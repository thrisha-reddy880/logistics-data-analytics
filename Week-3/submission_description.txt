This submission presents an end-to-end Week 3 logistics data analysis using Python, with a focus on exploratory data analysis, statistical summaries, visual communication, and practical operational recommendations. It includes a reproducible hypothetical logistics dataset with order dates, actual and scheduled delivery durations, shipping modes, transport distances, freight costs, quantities, customer segments, regions, and delivery status. The Python workflow validates and prepares the data, handles missing values, removes duplicate rows, derives delay and schedule-variance measures, calculates central tendency and descriptive statistics, compares performance across shipping modes and customer segments, examines regional and monthly patterns, and computes correlations between numeric variables.

The report contains six visualizations: a delivery-time histogram, late-delivery comparison by shipping mode, freight-cost box plot, distance-versus-freight scatter plot, monthly order-volume trend, and delivery-time comparison by customer segment. Each visualization is selected to answer a specific analytical question and is accompanied by an interpretation. The report also explains key performance indicators, the meaning and limitations of correlation, and recommendations for monitoring schedule variance, benchmarking freight costs by distance, reviewing outliers, planning capacity, and improving data collection.

The project includes the Word report, Python source code, dataset, exported summary tables, chart images, requirements file, and README with setup instructions. Running the script regenerates the analysis outputs. The dataset is explicitly simulated for demonstration and does not contain real company or customer records; therefore, the results must not be presented as findings from an actual business. The workflow can be adapted to an approved cleaned dataset when real operational data is available and permitted for use.
